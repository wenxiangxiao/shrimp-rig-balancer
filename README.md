# 🦐 釣蝦線組配重台

單檔 HTML 網頁工具，用來設計與試算釣蝦線組的配重，即時看出「露出目數／殘餘浮力／要加減多少鉛」。手機優先、深色介面、免安裝、不需連網。

## 功能

- **視覺化線組**：水面、浮標、天秤上下分段，把配件擺到對應位置。
- **材料庫**：右下角「＋ 加配件」按鈕開啟底部材料庫，收錄上目印、太空豆、浮標座、快別、八字環、夾鉛、天秤、蝦鉤、餌等常見配件；按住材料拖到線組對應那一段放開即加入。
- **浮標設定**：浮力（分）、標尾目數、每目長、標尾粗細。
- **即時試算**：依配件在水中的有效重量（考慮比重浮力），算出露出目數與殘餘浮力，紅／黃／綠燈提示。
- **調目建議**：輸入想露出的目數，直接告訴你要加鉛還減鉛幾克、約幾顆夾鉛／微調鉛。
- **複製摘要**：一鍵把整組配置複製成文字。

## 計算原理

- 浮力 ＝ 分 × 0.375 g（1 號 ＝ 10 分 ＝ 3.75 g）
- 每目浮力 ＝ π × (標尾半徑)² × 每目長度
- 配件水中重 ＝ 乾重 ×（1 − 1 ÷ 比重）；比重 < 1 的配件會提供浮力
- 露出目數 ＝ 總目數 −（水中總配重 − 浮標浮力）÷ 每目浮力

> 材料重量為常見概值，用電子秤實測後修改會更準。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，無任何相依套件。
